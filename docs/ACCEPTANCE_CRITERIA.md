# MVP 验收标准

状态：accepted for M1 design

## 基线与信息质量

- AC-001：每条 Observation 有时间、来源、敏感等级和质量信息；
- AC-002：每条 Claim 有证据引用、置信状态和复核时间；
- AC-003：Claim 或 Recommendation 不得显示为用户确认事实；
- AC-004：用户纠错创建修订并使旧 Claim 退出当前决策；
- AC-005：输入不足时输出 Unknown，而不是强行判断。

## 目标、机会与计划

- AC-101：active Goal 包含成功条件、时间范围和约束；
- AC-102：Opportunity 可追溯到 Goal 与 Baseline 的差距；
- AC-103：Recommendation 展示影响、成本、周期、风险、可逆性、依据和替代项；
- AC-104：Plan 有限周期且经过用户批准；
- AC-105：Task 有完成条件、频率/截止、依赖和停止条件。

## 执行与反馈

- AC-201：只记录真实完成，跳过和失败是合法状态；
- AC-202：可记录困难、不良反应和约束变化；
- AC-203：计划调整引用触发记录并保留旧版本；
- AC-204：显著扩大风险或成本的调整重新确认；
- AC-205：周期结束必须进入 Review，不得静默无限续期。

## 复盘与学习

- AC-301：Review 比较基线、目标、执行、结果与混杂因素；
- AC-302：结论区分有效、无效、不确定和执行不足；
- AC-303：模型修订记录前后值、理由、来源和确认状态；
- AC-304：下一轮方案说明基于哪些反馈改变；
- AC-305：同一事件序列得到确定一致的当前状态。

## 数据、权限与安全

- AC-401：D3 处理前说明用途、范围、保留和撤销；
- AC-402：D4 不进入持久状态、事件载荷或日志；
- AC-403：R2+ 行动按风险矩阵确认；
- AC-404：R3 外部动作在 MVP 中只生成草案；
- AC-405：R4 请求被拒绝并给出安全替代或升级边界；
- AC-406：撤销 Consent 后停止新的相关处理并产生审计事件；
- AC-407：导出与删除的范围、结果和限制可解释。

## MVP 成功判断

- 结果可追溯到目标、依据和行动记录；
- 至少一次反馈导致可解释的计划或 Claim 修订；
- 过期/撤销信息不继续用于当前建议；
- 用户认为行动清晰度或复盘价值高于一次性对话；
- 记录负担、隐私风险和建议错误没有抵消价值。
