## 判定与下一步

- W1 通过需要 D1、D2、A1、A2 全部通过，单独 A1 不能代表应用闭环通过。
- W2 通过还需要 U1、U2、R1、R2 全部通过；用户反馈不能由测试脚本代填。
- B1 的私有卷备份包含安装密钥和登录凭据，不代表 W4 的无凭据网页历史导出完成。
- W3 的变化展示与 X1 跨 Agent 接续分别记录；不得用第二个 fixture 替代真实服务。
- 上述验收不是 2–6 周效果验证，也不代表 Android 真机或 DOGFOOD_READY 通过。
