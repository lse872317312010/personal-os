# Personal OS：Web 阶段记录

更新日期：2026-10-30（Asia/Shanghai）。

## 当前结论

Web 自动 Agent 原型与私有部署恢复流程已通过自动化验证；真实账号推理、OCI
上机与同一目标两轮实际使用仍未验收。PR #133 为未合并草稿，接续 PR #131。

Personal OS 保存结构化个人资料和连续行动历史，所选 Agent 提供计划、复盘和
修订。当前主线是 Web + Node 网关：可从源码本机运行，也可在用户自己的 Oracle
Ubuntu Arm 实例运行，再由 SSH 隧道访问。云实例尚未实际部署。

默认私有部署使用 Codex CLI 的 ChatGPT 账号登录，不要求 API key，也不会自动
切到付费 API。账号权限和额度仍需真实验证。GitHub Pages 无法独立承载当前网关。
桌面包维护、Android 真机、设备同步和多 Agent 编排后排。

## 已实现与修复

- 自动发送结构化目标、成功标准、现状、限制和历史，接收计划/复盘/修订；无需手动搬运 JSON。
- 计划与复盘等待用户确认，完成与跳过由用户明确反馈；事实追加保存，切换 Agent 保留历史。
- 刷新恢复资料、行动和待完成请求；保存失败保留输入，重试不重复写入结果。
- 修订计划可展开“这轮为什么调整”，分别查看 AI 理由、已接受复盘建议和精确版本的结果原文；缺失/歧义明确提示。
- 网页可打开独立历史下载页，导出 `personal-os.web-history.v1` JSON，保留所有事件与固定版本引用。只读取历史命名空间，不打包连接配置、CLI 登录文件或安装密钥；用户写入的内容原样保留，文件是明文。导出不修改历史、不调用 AI，网页恢复尚未实现。
- Codex 连接表单隐藏 API 地址与密钥；未登录显示服务器登录命令。
- 模型列表为空或请求中授权失效时清除失效就绪状态；额度耗尽保留计划和反馈。
- 重新登录和重连不重复已失败的自动复盘，显式重试后才再次请求。
- `start` 校验完整包并重建容器，避免只构建新镜像却继续运行旧容器；命名资料卷保留。
- 备份/恢复固定采用脚本目录的 Compose 文件，忽略无关工作目录与遗留 `COMPOSE_FILE`；保留显式项目名。
- 备份排除 CLI 可重建的临时链接；恢复拒绝链接、越界、运行中服务与非空卷。
