# MVP 冻结范围

- 版本：v0.1
- 状态：accepted for M1
- 领域入口：外形优化
- 产品主线：最小分析能力 + 完整行动反馈闭环

## 要验证的命题

在有限外形分析能力下，Personal OS 能否通过可追溯基线、机会排序、行动计划、真实执行记录和复盘校准，比一次性聊天产生更持续、可验证的价值。

## 必须包含

1. 建立带日期、来源、质量和用户确认状态的外形基线；
2. 明确目标形象、时间、预算、偏好、健康和不可接受项；
3. 区分 Observation、Claim、Recommendation 与 Unknown；
4. 在有限维度内生成改善机会并说明依据；
5. 按影响、成本、周期、风险和可逆性辅助排序；
6. 选择少量机会形成有限周期 Plan 和可验证 Tasks；
7. 记录完成、跳过、困难、不良反应和用户纠错；
8. 周期结束生成 Review，并创建带理由的新状态版本；
9. 支持查看来源、纠错、撤销、过期、导出和删除语义；
10. 对 D3 数据和 R2+ 行动执行数据与人工确认规则。

## 最小分析范围

- 发型与整体形象表达；
- 护肤/皮肤状态的非医疗观察；
- 穿搭与体态的可观察项；
- 与健身和饮食的目标/约束关联。

面部骨相精细量化、医美方案、医学诊断和普适审美排名不属于 MVP 必需能力。

## 明确非范围

- 多用户和商业化；
- 自动联系第三方、购买、预约或公开发布；
- 医疗诊断、治疗或高风险不可逆建议；
- 全自动长期 Agent；
- 同时完成四个领域的完整产品；
- 社交关系对象画像或第三方敏感数据积累；
- 精确的计算机视觉评分模型；
- 技术栈、云厂商或模型供应商锁定。

## 首轮周期

产品契约按 2–6 周可配置设计，具体 dogfooding 周期在 M3 启动前确定。

## 变更规则

新增功能默认进入 backlog。只有完成主闭环、安全或验收必需项，才能通过决策记录纳入 MVP。
