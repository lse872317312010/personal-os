# 0019 — 暂停桌面版本维护，直接验证 Web

日期：2026-10-08

状态：Accepted，依据用户“先不要搞 windows / Linux 版本的维护，你在 web 端上测试就行”。

## 决定

当前工作集中在编译后的 Web 页面与自动 Agent 闭环。用户报告 Windows 启动停在批处理黑框；该启动问题后排，不在本轮修复，也不作为浏览器测试的入口。

Web CI 不再构建 Windows/Linux 便携包，不再更新桌面滚动发布。历史包和平台代码保留；Windows core 工作流改为手动触发，既有 Windows spike 仍只允许手动触发。测试所用 Ubuntu 运行器只是浏览器和网关的执行环境，不是 Linux 版本交付。

直接由测试代码启动 Node 网关，在隔离 Chrome 中加载真正的编译产物。分别验证 390×844 和 1440×900 浏览器尺寸，从连接表单开始，经过保存目标、自动计划、用户确认、明确反馈、自动复盘、下一轮和刷新恢复，保留截图。

公开静态站点仍是既有下载入口，不能独立承载凭据、加密历史和模型回调服务。本次不把该入口冒充线上推理应用，也不引入未经验证的云端个人数据存储。

## 验证边界

连接由真实 UI 保存，历史、协议和传输经过真实网关；模型回复仍来自明确的测试 Agent。真实 GPT 授权与推理、Windows 黑框修复、桌面启动包和 Android 真机验收都未由浏览器测试证明。

该决定覆盖 0018 中继续维护 Windows/Linux 启动包及每轮发布桌面包的安排；其他资料和用户决定边界继续适用。
