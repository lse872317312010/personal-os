# 0018 — 聚焦 Web 可用性与真实 Agent 闭环

日期：2026-10-02

状态：Accepted，依据用户“先聚焦 web 端”的明确优先级。

## 决定

近期交付集中在现有单页 Web 应用：行动清晰、AI 接入便利、个人资料可查看、历史可延续。Windows/Linux 本机服务继续承担凭据和加密存储，公开站点继续提供下载；本次优先级调整不引入云端个人数据存储。

Android 真机自动接入、Web/Android 同步和设备端扩展后排，不作为 Web 使用入口或每轮交付的前置条件。共享核心仍保持兼容，现有 Android CI 可继续自动回归。

Web 近期顺序：

1. 区分“连接已配置”和“模型实际响应”，允许用户在生成行动前测试连接；
2. 首页继续突出行动，把已保存个人资料和行动历史分别收进折叠卡片；
3. 验证个人条件、执行结果和接受的复盘确实进入下一轮实际请求；
4. 在用户授权后完成真实 GPT 两轮闭环验收，再逐步扩展个人资料管理。

连接测试由用户主动触发，仅向选定模型发送固定测试内容，不读取个人资料、不返回模型原始回复、不创建策略或历史事件。UI 明示服务可能计入用量。测试成功只证明服务完成了模型响应；正式行动计划仍由现有协议和用户确认流程校验。

## 验证

- 网关测试连接仍执行 Host/Origin、CSRF、连接版本和并发请求限制；
- 服务错误、连接切换、超时或过期回复不改变当前行动和历史；
- Flutter/Chrome 覆盖窄屏连接测试、长模型名，以及个人资料和历史展开；
- 编译后浏览器通过真实本机网关验证测试按钮，模型响应由明确的测试替身提供；
- 测试替身不计为真实 GPT 推理或真实执行效果验收。
