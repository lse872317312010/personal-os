# 0002 — MVP 采用最小分析与完整闭环

- 状态：accepted
- 日期：2026-08-20
- 范围：M0–M3

## 决定

首个 MVP 以外形优化为入口，采用“最小分析能力 + 完整行动反馈闭环”，而不是先构建全面的一次性外貌分析器。

## 理由

- Personal OS 的差异价值来自跨时间的行动与反馈；
- 完整闭环能尽早验证跨领域核心语义；
- 限制分析范围可降低审美偏差、健康越界和 D3 风险；
- 该切片更容易验证向健身、饮食和关系领域迁移的可能性。

## 影响

- M1 优先建立核心数据模型和事件日志；
- M2 技术方案必须支持可追溯、版本化和撤销；
- M3 才运行真实外形 dogfooding 周期；
- 全维度外貌分析进入后续 backlog。
