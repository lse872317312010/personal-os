# 产品原则与边界

## 产品原则

1. **真实闭环优先**：价值来自策略被执行、结果被记录并改变下一轮策略，而不是对话长度。
2. **数据与推理解耦**：Personal OS 保存权威资产和历史；Agent 负责推理，二者通过稳定协议协作。
3. **Agent 可替换**：Codex、其他模型、Agent 或 Harness 都只是客户端，不得成为数据格式和业务规则的依赖。
4. **Android 权威**：MVP 中 Android Vault 是个人资产、策略、执行与结果的唯一权威端。
5. **事实分层**：用户陈述、设备/人工观测、确定性结果、主观反馈、Agent 推断和建议必须可区分。
6. **历史不可伪造**：修订通过新事件表达，不覆盖既有执行和结果。
7. **策略是一等资产**：策略必须有目标、假设、适用条件、预期结果、评价指标、版本和来源。
8. **统一写入边界**：Android UI、MCP和文件导入都调用相同的 Application Commands，不能直接写数据库。
9. **用户最终控制**：用户可以确认、修改、拒绝、归档、导出、恢复和删除。
10. **兼容与退出能力**：核心数据使用稳定、可读、可版本化的协议，不锁定模型厂商或 Harness。
11. **先完成最小循环**：两轮真实策略迭代优先于 Windows、同步、多 Agent、知识图谱和高级自动化。
12. **安全边界内优化**：医疗、法律、金融和关系等高风险行动保持人工确认与升级边界。

## Agent原则

- Agent可以查询个人上下文、维护资产、提出策略、生成计划和写入复盘；
- Agent写入必须带来源、时间、对象版本和信息类型；
- Agent推断不得伪装成用户事实或确定性结果；
- Agent不得修改历史执行结果；
- Agent不得绕过状态机直接把候选策略标记为已验证有效；
- 更换Agent不影响历史连续性；
- 模型不可用时，已保存数据仍可读取、编辑、导出和恢复。

## 当前非目标

- Android内置或直接绑定OpenAI、Anthropic或其他模型；
- 在App内构造Agent或Prompt Harness；
- 多Agent调度与自动模型选择；
- 渐进披露、隐私效用优化等高级策略；
- Windows、iOS和Web客户端；
- 多设备E2EE同步；
- 自动联系第三方、购买、预约或公开发布；
- 训练个人神经网络模型；
- 同时完成所有生活领域。

## 伦理与安全边界

- 关系功能仅面向成年人、合法、自愿且尊重边界的互动；
- 不把审美偏好包装成客观缺陷；
- 不把Agent建议包装成医学、法律或金融专业结论；
- 高影响策略表达依据、未知项、风险和停止条件；
- API key、密码、验证码、私钥和恢复码不进入业务资产或Agent上下文。
