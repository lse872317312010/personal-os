# 术语表

| 术语 | 定义 | 不等于 |
|---|---|---|
| Personal OS | 跨时间、跨领域的个人决策闭环系统 | 单一聊天机器人或生活记录 App |
| AI-native | AI 参与理解、规划、解释和校准，但受数据、权限与审计约束 | 无人监督的全自动代理 |
| 决策闭环 | 基线、目标、差距、方案、执行、结果和复盘形成连续链路 | 只生成一次建议 |
| Dogfooding | 创建者本人以真实问题持续使用并验证系统 | 将个人偏好直接当成市场需求 |
| 基线 Baseline | 带时间、来源、质量和确认状态的领域状态快照 | 永久不变的用户画像 |
| 观察 Observation | 对输入或现实状态的记录 | 对原因和意义的推断 |
| 声明 Claim | 可被支持、质疑、过期或撤销的判断 | 绝对事实 |
| 机会 Opportunity | 基线与目标之间可干预的候选差距 | 已确定必须执行的任务 |
| 建议 Recommendation | 基于目标、证据和约束提出的行动选择 | 自动授权执行 |
| 计划 Plan | 经确认、有限周期的一组行动 | 无限期习惯或模糊愿望 |
| 复盘 Review | 比较目标、执行和结果并修订模型的过程 | 只统计完成率 |
| 证据等级 | 对需求来源可靠程度的标记 E0–E3 | 需求优先级或实现难度 |
| 敏感等级 | 数据泄露或误用风险 D0–D4 | 信息真实性 |
| local-first | 本地数据与能力具有优先地位，具体同步边界待需求确定 | 完全离线或禁止云端 |
| 长期记忆 | 可查看、可纠错、带生命周期的持续上下文 | 永久保存全部聊天 |
| V × T × A × M | 关系模块的瓶颈分析框架 | 人的单一价值评分 |
| 人工确认点 | 高风险、外部影响或不可逆动作前的用户授权节点 | 每一步都要求用户点击 |
